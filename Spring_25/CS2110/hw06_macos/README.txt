MVP

This game is a representation of an mvp which utilizes the existing garbage image to be moved around the screen in the pursuit of finding
a treasure chest (Represented by a green box)

Contains:
Title screen with animated image and text
    The title bounces up and down, while the image moves in a diagonal pattern.

Initiation of the actual game by pressing the return key
    Using the d-pad, the image can be moved both in the x- and y- directions in pursuit of the treasure chest
    Text is available on the screen giving instructions on how to move around the screen and how to return to the initial page
    A time is in the top left corner
    The delete button will reset the game

How to control
    D-pad will move the player in the x- and y- directions in pursuit of the treasure chest
    The return button will start the game
    The delete button will return you back to the home screen both during the game and once you have completed the game
